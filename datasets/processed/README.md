# Processed Data

Intermediate preprocessed artifacts (tokenized text, vectorized matrices, train/val splits) generated by the `ai-engine/` pipeline. These files cache expensive preprocessing steps to speed up iterative model training.

## Files

| File | Description |
|---|---|
| `tokenized_texts.pkl` | Tokenized + stopword-removed + stemmed email texts |
| `tfidf_vectors.pkl` | Cached TF-IDF sparse matrix (30k features) |
| `train_indices.npy` | Row indices for the training split |
| `test_indices.npy` | Row indices for the test split |

## Generation

```bash
python ai-engine/training/build_final_dataset.py
```

This reads `datasets/final/final_emails.csv`, applies preprocessing, vectorization, and writes cached artifacts to this directory for reuse during model training and evaluation.
